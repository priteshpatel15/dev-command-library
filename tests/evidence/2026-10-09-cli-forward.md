## Retained failures, corrections and limitations

1. **Discovery fix:** the initial setup's native read-only discovery created `xdg-config/openspec/config.json` before first-run analytics had been disabled. This was an isolated test-directory write, not a user-wide OpenSpec mutation, but exceeded the initially narrower request boundary. The candidate was corrected to set process-local `OPENSPEC_TELEMETRY=0` for discovery/status. A fresh first-run status evaluation without an inherited telemetry setting proved zero writes afterward. Original failure receipts remain retained.
2. **Instruction identity changed:** after work, the parent corrected the command card's initialized-empty-project next action to avoid `status` recommending itself. This changes `commands.md` identity only; it does not change work/verify/finish gates. The fresh verify evaluator discovered that identity difference, preserved its initially failed blanket identity assertion, reviewed current instructions, and reran runtime acceptance rather than pretending all skill hashes matched.
3. **Invalid missing-skill attempt:** an early override using embedded quotes in `plugins."ponytail@ponytail".enabled=false` left Ponytail enabled. That attempt (`missing-skill-*`) is unscored and is not evidence of bypass. The corrected supported dotted key `plugins.ponytail@ponytail.enabled=false` produced a real disabled catalog; cached files still physically existed. This is session-catalog isolation, not filesystem isolation.
4. **Host config caveat:** `/Users/po/.codex/config.toml` changed hash during concurrent native Codex sessions. No prelaunch content copy exists, so changed keys cannot be attributed. The disabled evaluator transcript contains no configuration writes; current persistent Ponytail remains enabled. No unknown changes were reverted. The dependency branch passes, but it does not prove the whole host configuration stayed byte-identical.
5. **Retention and scope:** raw evidence uses explicit absolute temporary path bases and must be retained or copied with a relocation map before deleting that directory. The effort-revision evaluator made a disposable `/private/tmp/article-tooling-revise-jwctoeuv` backup; its bytes were also retained at `raw/revise-effort-backup/`.
